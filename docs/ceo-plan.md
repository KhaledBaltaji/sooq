## Vision

### 10x Check
The 10x version isn't just a betting platform — it's the Arabic-language Bloomberg Terminal for political risk. Markets become the de facto odds source cited by MENA journalists, diplomats, and analysts. Every WhatsApp political argument ends with "what do the markets say?" The platform becomes infrastructure: an API that news sites embed, a data feed that think tanks cite, a prediction engine that insurance companies use for political risk pricing.

## Accepted Scope (added to this plan)
- WhatsApp/Telegram shareable market preview cards (OG meta + dynamic image)
- Push notifications for market resolution, wins, and referral events
- Deposit bonus system ($5 free on first deposit, 2x wagering requirement)
- Anonymous live activity feed ("User #4521 bet $25 on YES")
- Simulated initial activity for first 48 hours (cold start)
- Rich political context on market detail pages

## Architecture Decision
- Supabase-only architecture (no separate Node.js backend)
- Next.js (Vercel) → Supabase (Postgres + Auth + Realtime + Edge Functions)
- Edge Functions for webhooks + admin operations
- Postgres functions for all financial logic

## Security Additions
- 3pay webhook authentication: HMAC verification + on-chain tx verification + idempotency key + rate limiting
- Bet placement race condition: explicit test for concurrent bet + resolution

## Deployment Resilience
- Primary .com domain behind Cloudflare
- Mirror domain on different registrar
- Telegram bot + WhatsApp broadcast for domain change announcements
- PWA approach for domain-change survival

## Cold Start Strategy
- Simulated activity feed for first 48 hours
- Rich political context on market detail pages (news links, analysis, timelines)
- Content-first approach: markets are interesting even with 0 bets
