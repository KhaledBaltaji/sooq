THE AMM MODEL — HOW IT WORKS

Core Concept

Each market has an Automated Market Maker powered by the LMSR (Logarithmic Market Scoring Rule) formula. The AMM acts as the counterparty to every trade. Users buy and sell shares against the algorithm, not against each other.

  • YES shares pay $1.00 if the outcome is YES, $0.00 if NO.
  • NO shares pay $1.00 if the outcome is NO, $0.00 if YES.
  • YES price + NO price always equals approximately $1.00.

The LMSR Formula

Cost function: C(q) = b * ln(e^(q_yes/b) + e^(q_no/b))

Where:
- b = liquidity parameter (your seed amount, e.g. 1000)
- q_yes = total YES shares outstanding
- q_no = total NO shares outstanding
- Price of YES = e^(q_yes/b) / (e^(q_yes/b) + e^(q_no/b))
- Price of NO = e^(q_no/b) / (e^(q_yes/b) + e^(q_no/b))

To buy N shares of YES:
cost = C(q_yes + N, q_no) - C(q_yes, q_no)

To sell N shares of YES:
payout = C(q_yes, q_no) - C(q_yes - N, q_no)

Key Properties

  • Always liquid. The algorithm always quotes a price. No counterparty needed. Works with 1 user or 100,000 users.
  • Price moves with trades. Buying YES pushes YES price up and NO price down. Self-balancing.
  • Max loss is capped at the liquidity parameter (b). If b = $1,000, you cannot lose more than $1,000 on that market regardless of what happens.
  • Spread is built into the formula. The buy price is always slightly higher than the sell price. This spread is invisible to users and is your primary revenue source.

Market Lifecycle

  1. Admin creates market with question, resolution criteria, and dates
  2. AMM is initialized with liquidity parameter b = $1,000. Starting price: YES $0.50, NO $0.50
  3. Users buy and sell shares. Prices move with every trade
  4. Betting closes 2 hours before resolution time
  5. Admin resolves market: YES shares pay $1.00 OR NO shares pay $1.00
  6. All outstanding shares are settled automatically
  7. AMM liquidity parameter (seed) is returned to treasury +/- the AMM's P&L on that market

FEE ARCHITECTURE — SUBLIMINAL MODEL

Core principle: User sees "0.5% trading fee." User actually pays ~5% per round trip. The difference is invisible, built into AMM pricing.

What the user sees: "0.5% trading fee"

This is the only fee mentioned in docs, FAQs, and UI. It appears as a line item on trade confirmations. On a $25 trade, user sees "$0.13 fee." Feels like nothing.

What actually generates revenue (invisible to user):

Layer 1: Explicit trading fee — 0.5%

Shown on every trade receipt. User sees this and thinks it's the total cost. Applied on every buy and every sell.

Layer 2: AMM spread — 2-3%

Built into the LMSR formula via the liquidity parameter. Buy price is always higher than theoretical fair price. Sell price is always lower. User sees ONE price — "YES: $0.62" — with no reference price to compare. They cannot calculate the spread because there is no visible order book. Controlled by adjusting the liquidity parameter: lower b = wider spread = more revenue. Target: ~1.5% spread on entry, ~1.5% spread on exit.

Layer 3: Resolution fee — 1%

When market resolves, winning shares pay $0.99 instead of $1.00. User sees "Payout: $0.99 per share" and accepts it as normal. 1% of all winning payouts goes to platform.

Layer 4: Dynamic spread widening — 0.5% average

When a market is volatile or heavily one-sided, the algorithm automatically widens the spread. User just sees "the price moved." Kicks in when imbalance exceeds 65/35. Also widens during the last 4 hours before close.

Layer 5: Cash out premium — 0.5%

When user sells before resolution, add 0.5% "instant settlement" surcharge. Shown as part of the sell price, not as a separate line item.

Effective take rate per round trip: ~5%

COPY TRADING — DETAILED

How It Works

  1. User B taps "Copy" on User A (leader)
  2. Sets copy amount per trade
  3. Every leader trade auto-executes for copier through the AMM
  4. Each copy trade generates fees like a normal trade
  5. Copier can pause, resume, or manually override anytime

Leader Incentive

  • 10% of NET PROFIT generated for copiers
  • If copiers profit $500/month, leader earns $50
  • $0 if copiers lose (no negative commission)
  • Credited weekly
